# kakobuyoe.shop

An independent Kakobuy **product-discovery guide** — static, zero dependencies, four languages
(English / 简体中文 / Español / Português).

Live: https://kakobuyoe.shop (Cloudflare Pages, `main` branch of this repository)

## What is here

| Path | Contents |
|---|---|
| `index.html` | English home |
| `zh/` `es/` `pt/` | The same 26 pages in Chinese, Spanish and Portuguese |

| `sitemap.xml` `robots.txt` | 104 URLs with four-language `hreflang` alternates + x-default |

104 indexable pages + a `404.html`, no client-side JavaScript, no third-party scripts,
no analytics, no cookies.

## Editorial rules

* No page claims any item is authentic, and no warehouse photograph is presented as proof.
* No affiliation with Kakobuy or any marketplace is implied; the footer states this explicitly.
* Nothing is sold here: no cart, no account, no payment. Orders happen on the platform the reader chooses.
* No prices are quoted — source prices change faster than any static page can track.

## Source & pipeline

Generated by a small Python toolchain (not committed here) from the catalogue snapshot:

```
fetch_data.py   ->  _data_cats.json / _data_prods.json     (catalogue snapshot)
build.py        ->  dist/                                   (this repository's contents)
check.py        ->  structural + SEO assertions (must pass before pushing)
push_gh.py      ->  Git Data API single-commit push
```

`check.py` enforces, among other things: exactly one `<h1>` per page, canonical and `hreflang`
on every page, a valid JSON-LD block on every page, no `Product` structured data (the catalogue
carries no price field, so `Product` markup would be invalid), `sitemap` element order
(`loc` → `lastmod` → `xhtml:link`, which Google's schema requires) and no forbidden wording.

Product links point at the source catalogue. Product and brand names appear for identification
only and belong to their respective owners.
